# Звёздное Веретено — компендиум

Модуль с компендиумами для системы [«Звёздное Веретено»](https://github.com/dabradac/star-spindle_fvvt) (Foundry VTT v13, система 0.3.0+).

| Особые способности | 150 способностей от 15 навыков по уровням 1–5 и 20 практик ведовства (4 ветки); активные отмечены, условные бонусы — тоже |
| Черты и ремёсла | 33 положительные и 42 отрицательные черты, 4 ветки ведовства, 6 ремёсел |
| Оружие | 24 вида оружия ближнего боя, 53 — дальнего, модификации и боеприпасы |
| Броня и щиты | 23 доспеха, 3 щита, улучшения брони |
| Снаряжение | Повседневные предметы, медицина, боевые эликсиры, выживание, слежка, наука, культура, кибершаманские и ведовские предметы, заговоры, взрывчатка |

| Травмы | 36 травм из таблицы к66; штрафы к навыкам — активными эффектами |

При первом запуске Мастером модуль сам прописывает таблицы к66 в настройках системы, если там пусто:
кнопки «Травма (к66)», «Крит. повреждение (к66)» и др. сразу показывают результат из таблицы.

Описания существ даны кратким пересказом; характеристики и механика — по книге правил. Рейтинг опасности
существ в книге нарисован значками и перенесён вручную.

## Установка

Репозиторий приватный, поэтому Foundry не сможет скачать модуль по ссылке на манифест. Скачайте
`star-spindle-compendium.zip` из релиза и распакуйте в `Data/modules/star-spindle-compendium/`
(внутри должен лежать `module.json`), затем включите модуль в мире.

## Релиз

Создайте релиз с тегом вида `v0.1.0` — GitHub Actions подставит версию в `module.json`
и прикрепит к релизу `module.json` и `star-spindle-compendium.zip`.

## Сборка

Исходники паков — JSON по документу на файл в `src/packs`, они генерируются из данных в `tools/data`:

```bash
npm install
npm run build   # python3 tools/build.py && упаковка в packs/ (LevelDB)
```

`npm run unpack` распаковывает `packs/` обратно в `src/packs` (например, после правок прямо в Foundry).

Чтобы поправить данные, меняйте файлы в `tools/data` и пересобирайте. Идентификаторы документов стабильны
(вычисляются из названия), поэтому ссылки на предметы в мирах не ломаются при пересборке.
