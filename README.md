# Звёздное Веретено — компендиум

Модуль с компендиумами для системы [«Звёздное Веретено»](https://github.com/dabradac/star-spindle_fvvt) (Foundry VTT v13, система 0.4.0+).

Бестиарий, артефакты, таблицы и справочник Мастера игрокам по умолчанию не видны.

При первом запуске Мастером модуль сам прописывает таблицы к66 и к6 в настройках системы, если там пусто:
кнопки «Травма (к66)», «Крит. повреждение (к66)», «Крит. повреждение ТС (к6)» и др. сразу показывают результат из таблицы.

Описания существ, артефактов и технологий даны кратким пересказом; характеристики и механика — по книге правил.
Главы о мире игры перенесены из текста книги (`tools/data/lore.json`, обновляется командой
`python3 tools/build.py --lore <папка со страницами книги>`). Рейтинг опасности
существ в книге нарисован значками и перенесён вручную.

## Установка

В Foundry: «Дополнения» → «Установить модуль» → вставьте ссылку на манифест:

```
https://github.com/dabradac/star-spindle-compendium/releases/latest/download/module.json
```

Либо скачайте `star-spindle-compendium.zip` из релиза и распакуйте в `Data/modules/star-spindle-compendium/`
(внутри должен лежать `module.json`). Затем включите модуль в мире.

## Релиз

Создайте релиз с тегом вида `v0.1.0` — GitHub Actions подставит версию в `module.json`
и прикрепит к релизу `module.json` и `star-spindle-compendium.zip`.

## Сборка

Исходники паков — JSON по документу на файл в `src/packs`, они генерируются из данных в `tools/data`:

```bash
npm install
npm run build   # python3 tools/build.py && упаковка в packs/ (LevelDB)
```

`npm run unpack` распаковывает `packs/` обратно в `src/packs` (например, после правок прямо в Foundry).

Чтобы поправить данные, меняйте файлы в `tools/data` и пересобирайте. Идентификаторы документов стабильны
(вычисляются из названия), поэтому ссылки на предметы в мирах не ломаются при пересборке.
